# Hi, I'm Yader 👋

**Data engineer and platform developer** from Nicaragua 🇳🇮. Four years in the same agro-industrial and financial group, moving up from maintaining a credit monolith to building its data platform.

I build the whole pipeline: from pulling reliable data out of a legacy ERP to the screen where someone makes the decision. Almost always with the old system still running, because there is no window to turn it off.

## What I work on

- **Data platform:** metadata-driven ingestion from MariaDB, a medallion warehouse (bronze → silver → gold) with Kimball modeling in dbt, and Airflow orchestration chained by data events.
- **Trustworthy numbers:** gold reconciled against the source ERP, incremental loads verified against full rebuilds, and data quality that flags rows instead of hiding them.
- **Models in production:** a forecasting model inherited as notebooks, turned into a daily run with a memory budget, off-by-default switches, and a read-only API for the dashboard.
- **Backend:** company isolation and server-side calculations in a multi-company accounting system.

## Currently

- 🎓 MIT xPRO **Professional Certificate in Data Engineering**
- 🧪 Building personal data projects with synthetic and public data
- ☁️ Next on my list: a cloud warehouse and CI/CD for data

## Stack

- **Data:** Python · pandas · dbt · Airflow · PostgreSQL · MariaDB · DuckDB · Parquet
- **Backend:** TypeScript · NestJS · FastAPI · PHP / Yii2 · Node.js
- **Frontend:** Next.js · React · Astro · Tailwind CSS
- **Platform:** Docker · GitHub Actions · Linux

## Why most of my work is private

Most of what I've built was under contract: the code and data belong to whoever paid for them. My portfolio tells those projects through their constraints, decisions, and what went wrong, without exposing anyone's code or data.
